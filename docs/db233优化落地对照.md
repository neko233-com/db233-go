## 1. 总览

| 原建议项 | 优先级 | 状态 | db233-go 落地方式 | 备注 |
|----------|--------|------|-------------------|------|
| 2.1 `SaveBatchUpsert` | 高 | ✅ 已落地 | `SaveBatchUpsert` / `UpdateBatchUpsert` | 同表多行单 SQL；**跨表混合**自动 `groupEntitiesByTable` |
| 2.2 `FindByIds` / `FindByIdIn` | 高 | ✅ 已落地 | `FindByIds` + **`FindByIdsMap`** | slice 与 map 均可用 |
| 2.2 登录多表 | 高 | ✅ 已落地（增强） | `FindByIdConcurrent(id, entityTypes, config)` | 比 IN 更适合「一玩家多表各 1 行」 |
| 2.3 `UpdateBatch` 真批量 | 中 | ✅ 已落地 | `UpdateBatch` → 同表 `SaveBatchUpsert`（跨表自动分组） | 与 `UpdateBatchUpsert` 等价语义 |
| 2.4 Prepared Statement 缓存 | 中 | ✅ 已落地 | `PreparedStmtCache` + `enablePreparedStmtCache` | `stmtCacheSize` / `stmtCacheTTLSeconds`；另保留 `SqlTemplateCache` |
| 2.4 ORM 直扫 / map 池化 | 中 | ✅ 已落地 | `enableFastOrmScan` + `enableRowMapPool` + **`enableAllocPool`** | 字段 map / 批量 scratch / IN 占位符 / Builder |
| 2.4 冷启动预热 | 中 | ✅ 已落地 | `WarmGameDb` / `enableColdStartWarmup` | 池 + 元数据 + Stmt + OrmScanPlan |
| 2.5 连接池可观测 | 低 | ✅ 已落地 | `ConnectionPoolMonitor` + `HealthChecker.CheckConnectionPool` + `sql.DB.Stats()` | 需游戏服 `/api/monitor` 主动挂载 |
| 2.6 `SaveBatch` 语义 | 低 | ✅ 文档/注释 | `SaveBatch` = INSERT-only；更新用 `Save` / `SaveBatchUpsert` | 接口注释已区分 |
| 2.2 map 返回 | 高 | ✅ 已落地 | `FindByIdsMap(ids, type) (map[any]IDbEntity, error)` | 基于 `FindByIds` |
| 连接池配置 | — | ✅ 已落地 | `DbConnectionConfig` + `RegisterDbForConnectionPool` + performance JSON | `NewDb` 第二参数是 **dbId** 非 pool size |

### v1.0.0 额外能力（原建议文档未列，游戏服应使用）

| 能力 | API / 配置 | 用途 |
|------|------------|------|
| Session L1 + 延迟刷写 | `InitGameDb` → `SessionRepository` / `entityCache` | 在线读零查库、写 dirty 定时/下线落库 |
| 写缓冲 | `SaveBuffered` + `WriteBuffer` | 高频写合并 |
| 本地 WAL | `LocalWriteJournal` | 云 DB 故障不丢 |
| 负缓存（可选） | `negativeCacheEnabled` / `session.SetNegativeCacheEnabled` | 默认关；确认无记录后不重复 SELECT |
| 表名热路径缓存 | `ResolveEntityTableName` | 减少反射 |
| 框架压测 | `benchmarks/` | 对比 sqlx/GORM + 突发稳定性 |

## 2. API 对照（方法名 / 语义）

### 2.1 批量 UPSERT（原 2.1）

```go
repo.SaveBatchUpsert([]db233.IDbEntity{e1, e2, e3})
repo.UpdateBatchUpsert(dirtyEntities) // InitGameDb + WAL 后推荐
repo.UpdateBatchUpsert([]db233.IDbEntity{&PlayerBase{}, &PlayerBag{}}) // 跨表自动分组
```

配置：`batchUpsertChunkSize`（默认 200）。

### 2.2 批量读（原 2.2）

```go
list, _ := repo.FindByIds([]any{"p1", "p2"}, &PlayerBagEntity{})
items := repo.FindByIdConcurrent(playerId, []db233.IDbEntity{&PlayerBase{}, &PlayerBag{}}, nil)
session, _ := sessionRepo.OpenSession(playerId, loginEntityTypes)
_ = session.Get(&PlayerBagEntity{})
```

### 2.3 UpdateBatch（原 2.3）

```go
repo.UpdateBatch(entities) // 真批量 UPSERT，等价 SaveBatchUpsert（含跨表分组）
```

### 2.4 SQL / Stmt 缓存（原 2.4）

| 层级 | 实现 | 配置 |
|------|------|------|
| SQL 模板字符串 | `SqlTemplateCache` | `enableSqlTemplateCache: true` |
| `*sql.Stmt` 预编译池 | `PreparedStmtCache` | `enablePreparedStmtCache: true`, `stmtCacheSize: 256`, `stmtCacheTTLSeconds: 600` |

### 2.5 FindByIdsMap

```go
m, err := repo.FindByIdsMap([]any{"p1", "p2"}, &PlayerBagEntity{})
bag := m["p1"].(*PlayerBagEntity)
```

### 2.5 连接池（原 2.5）

```go
db := db233.NewDb(ds, 0, nil) // dbId，不是 pool size
db233.RegisterDbForConnectionPool(db)
stats := db.DataSource.Stats()
```
